# Apology React template

Run: npm install, then npm run dev.
Checks: npm run lint and npm run build.

Seven screens: welcome, letter, six reasons, eight memories, music, heart-catching game, ending and replay.

Artwork is pending. Replace placeholders by adding these files in public:
- images/memory-1.jpg through images/memory-8.jpg
- images/bunny-sad.png, images/bunny-smile.png, images/bunny-love.png
- audio/our-song.mp3

Music requires the audio file. Fonts load from Google Fonts with local fallbacks. Final artwork and visual fidelity refinements are pending.
